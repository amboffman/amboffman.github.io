# Design direction mockups — July 2026 redesign

Three candidate directions for the portfolio redesign. Each is a fully self-contained,
zero-build HTML file — open it directly in a browser (double-click, or via browser-sync)
to see the real motion, typography, and the working **⌘K / Ctrl+K command palette**.
Static previews live in `screenshots/`.

| | Direction | File | Vibe |
|---|---|---|---|
| A | **AI Command Center** | `a-command-center.html` | Dark terminal/dev-tool aesthetic. Typing AI terminal hero, dashboard-style metrics, mono details. "I build AI tooling." |
| B | **Enterprise Premium** | `b-enterprise-premium.html` | Linear/Stripe polish. Aurora glow, glass "ab-assistant" AI card, immaculate Inter type. "Senior, expensive, trustworthy." |
| C | **Editorial Bold** | `c-editorial-bold.html` | Warm paper, huge Archivo type, Swiss rules, signal-orange accents, magazine "interview" AI section. "Design-literate engineer." |

All three share: AI-session hero (animation completes ≤3s), working command palette,
`prefers-reduced-motion` support, real resume content (Senior Fullstack Engineer ·
6+ yrs · 18 enterprise apps · $1.1M revenue · 3 mentored), no frameworks, no Tailwind.

These are hero + one proof section only — the winning direction gets built out into the
full site (About, Experience, Case Studies, Skills, Contact) with self-hosted fonts.

This folder is a working artifact; delete it once the redesign ships.
